# Milano Couture - Virtual Suit Try-on 

A virtual try-on tool for milano couture allowing customers to upload a photo and see realisitc suit combinations mapped onto their body

## TECH STACK
- next.js 15 (typescript)
- Tailwind CSS
- supbase
- Git/ Github

## GETTING STARTED
1. Clone the repo
2 - Install dependencies: 
npm install
3 - Create a `.env.local` file with:
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPBASE_ANON_KEY=your_key
4. Run the development server:
npm run dev
5. Open http://localhost:3000
